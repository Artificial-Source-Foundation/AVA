# AVA Third-Party Notices

This notice applies to the AVA Linux binary distribution. It identifies the
direct source/header/object dependencies compiled into AVA and the audited build
tool recorded by release provenance. `ncursesw`/`tinfo` and `libc`, `libstdc++`,
`libgcc`, and `libm` are host runtime libraries dynamically loaded by the binary;
they are **not bundled** in the archive.

## cwds — MIT

**Usage boundary:** Carlo Wood's `cwds` source dependency, compiled into AVA
where selected by the build.

Copyright (c) 2000-2026 Carlo Wood

## cmake-aicxx — MIT

**Usage boundary:** Carlo Wood's CMake module dependency controls the AVA build.
It is a build tool and is not compiled into or bundled with this artifact.

Copyright (c) 2026 Carlo Wood

## ai-utils (`utils`) — MIT for AVA-used Carlo-owned paths

**Usage boundary:** AVA uses the MIT-licensed Carlo-owned paths pinned in the
`utils` source dependency for the qualified x86_64/x64 release. This notice does
not describe the whole `utils` repository as exclusively MIT. In particular,
`utils/FunctionView.h` is BSD-3-Clause and `utils/threading/MpscQueue.h` is
BSD-2-Clause-Views; both are excluded from AVA production sources and AVA builds
define `MIT_LICENSE_ONLY` so accidental future inclusion fails compilation.
The AArch64 `yield` branch in `utils/cpu_relax.h` has unresolved third-party
provenance; non-x86 architectures are not release-qualified pending provenance
or replacement.

Copyright (c) 2004-2026 Carlo Wood
