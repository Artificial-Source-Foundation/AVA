# AVA Interoperability

This category holds AVA's interoperability material. The normative ACP contract and support profile stay at the fixed `docs/` root paths ([`acp.md`](../acp.md) and [`acp-support.json`](../acp-support.json)); this index only owns the dated evidence beneath it.

- [ACP client evidence policy and reports](evidence/README.md): bounded, dated, manually reviewed interoperability observations and the rules for recording them.

Evidence is historical by nature: never cite a dated report alone as proof of current behavior. See the [documentation policy](../development/documentation-policy.md) for the document-class rules.
