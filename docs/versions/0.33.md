# AVA 0.33 Backend Maturity Ledger

AVA 0.33 tracks backend robustness and content-boundary work in small, verifiable slices. Keep this file updated as each slice lands so the release state is visible without reading commit history.

## Scope

- Keep backend events and command results semantic, typed, and layout-free.
- Keep frontend-owned content adaptation separate from terminal drawing.
- Reduce large coordinator files by moving cohesive helpers into narrow modules.
- Strengthen headless CLI/RPC coverage so backend behavior is testable without the TUI.
- Preserve provider, tool, permission, session, and config safety boundaries.

## Non-Goals

- Do not polish or redesign the visual TUI in this release ledger.
- Do not add terminal layout concepts to backend event or command contracts.
- Do not copy reference UI layouts, screens, or code.
