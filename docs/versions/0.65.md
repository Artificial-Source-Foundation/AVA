# AVA 0.65 Provider-Native Hardening

AVA 0.65 is the provider-hardening cut after the 0.60 backend platform catch-up. Its job is to move provider breadth from foundation-only to contract-backed and release-track.

This document tracks implementation status for the release-position line, not a shipped runtime version. Update the compiled project/runtime version only in a dedicated release-bump slice.

## Status

- OpenAI remains the fully supported default path.
- Anthropic Messages support now has native tool, thinking/signature, redacted-thinking, cache-usage, stop-reason, model-metadata, and fake transport/agent-loop coverage. Live credentialed streaming/non-streaming smokes are still deferred until credentials and a safe smoke environment are available.
- Kimi, Moonshot, and OpenRouter are registered OpenAI-compatible shims with built-in profile contract coverage for request shape, auth/header/base URL behavior, stream usage, error normalization, and context-overflow classification. `reasoning_content` coverage applies to Kimi/Moonshot-style compatible routes; built-in OpenRouter reasoning controls stay disabled until OpenRouter-native `reasoning`/`reasoning_details` handling is implemented.
- Provider-switch safety is already covered by runtime validation and focused model-switch tests; 0.65 does not add a broad history translation layer.
- 0.70 reasoning/model lifecycle closeout is bundled only for docs, focused tests, and small export polish.

## Goal

Ship OpenAI plus at least one additional production-quality provider path, with documented behavior for compatible providers and no provider-specific logic leaking into the agent loop.

## Scope

- Harden Anthropic Messages support beyond native `tool_use`/`tool_result`: stop-reason normalization, thinking blocks and signatures, cache-control hints, cache read/write accounting, request validation, model metadata, and fake streaming/non-streaming workflow coverage.
- Keep safe provider-switch behavior fail-closed before sending tool, result, or reasoning history that the target provider cannot accept.
- Validate Kimi/Moonshot/OpenAI-compatible provider shims against current public docs before coding assumptions into request builders.
- Cover Kimi/Moonshot/OpenAI-compatible paths with catalog aliases, credentials, request transforms, Kimi/Moonshot `reasoning_content` parsing/replay, OpenRouter-style SSE/error compatibility, context-overflow classification, fake contract tests, and limited credentialed smokes where practical.
- Document retry/idempotency policy per provider: idempotent, best-effort, or disabled for unsafe request classes.
- Extend model capability metadata only where needed for this cut; defer broad cache/strict-schema/pricing expansion unless tests require it.

## Exit Criteria

- OpenAI remains the fully supported default path.
- Anthropic can complete streaming and non-streaming native tool workflows through fake transport/agent-loop coverage; live credentialed CLI/transport smokes are documented as deferred when credentials are unavailable.
- Kimi, Moonshot, and OpenRouter-compatible routes have fake-provider contract coverage for request shape, streaming parse, usage parse, auth/base URL behavior, and normalized errors; Kimi/Moonshot-compatible routes additionally cover `reasoning_content` handling.
- Provider-switch tests cover tool-capable to non-tool, reasoning to non-reasoning, compaction-boundary, and compatible-family switches.
- Provider-specific compatibility code remains inside provider modules or narrow transform helpers.
- `docs/product/backend-capabilities-1.0.md` and `docs/roadmap/backend.md` are updated to reflect which providers are actually release-grade.

## Validation Evidence

- `cmake --build build` passed for the provider-hardening batch.
- Focused CTest regex `ava_tests\.(provider_openai|provider_anthropic|config_context_auth_oauth|session)$` passed 4/4.
- Earlier sub-batch validation also passed direct `provider_openai`, `provider_anthropic`, `config_context_auth_oauth`, `session`, and `git --no-pager diff --check` checks.

Deferred validation:

- Live credentialed Anthropic, Kimi, Moonshot, and OpenRouter smokes were not run in this environment. Treat the fake-contract coverage as offline release evidence, not proof of live provider availability.

## Not In This Cut

- Stable plugin API completion.
- Full reasoning UI polish.
- HTTP/server daemon mode.
